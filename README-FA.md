# سهمینه - پروژهٔ اندروید و وب‌اپ

کل برنامه در پوشهٔ `app/src/main/assets/` است. فایل اصلی `index.html` است. همین پوشه را می‌شود هم در اندروید و هم روی وب استفاده کرد.

## تنظیمات مهم (بالای script دوم در index.html، بخش `CFG`)
| مورد | توضیح |
|---|---|
| `support.telegram` | لینک تلگرام پشتیبانی. الان `https://t.me/YOUR_ID` است، حتماً عوضش کنید |
| `support.whatsapp / phone / email / hours` | هر کدام را پر کنید نمایش داده می‌شود، خالی باشد نمایش داده نمی‌شود |
| `buy.price` | قیمت اشتراک (متن، مثلاً «۵۰۰٬۰۰۰ تومان») |
| `buy.link` | لینک پرداخت. خالی باشد، دکمهٔ «خرید اشتراک» به تلگرام پشتیبانی می‌رود |
| `freeUntil` | آخرین ماه رایگان. الان دی ۱۴۰۵ (`{y:1405, m:10}`)؛ از ۱ بهمن ۱۴۰۵ رمز می‌خواهد |
| `passHashes` | هش رمزهای معتبر (نه خود رمز) |

## رمز فعال‌سازی
- رمز فعلی: `Sahmine@1405`. قبل از انتشار آن را عوض کنید.
- رمز جدید: فایل `tools/password-tool.html` را در مرورگر باز کنید، رمز را بنویسید، هش را کپی کنید و در `passHashes` بگذارید. چند رمز هم می‌توانید بگذارید (با کاما جدا کنید).
- هر کاربر فقط یک بار رمز می‌زند. بعد از آن روی همان دستگاه دیگر رمز نمی‌خواهد.
- قفل ساده و سمت دستگاه است، نه امنیت قوی. برای فروش عادی کافی است، ولی کسی که مهارت فنی داشته باشد می‌تواند دورش بزند.

## ساخت APK
**روش ۱: آنلاین (بدون نصب چیزی)**
1. در github.com یک مخزن خصوصی بسازید و محتویات این پوشه را (با پوشهٔ مخفی `.github`) آپلود کنید.
2. تب Actions ← «Build APK» ← Run workflow.
3. بعد از چند دقیقه `app-debug.apk` را از Artifacts دانلود کنید و روی گوشی نصب کنید.

**روش ۲: Android Studio**: پوشه را باز کنید و Build ← Build APK(s) را بزنید. فایل در `app/build/outputs/apk/debug/` ساخته می‌شود.

## وب‌اپ
محتویات پوشهٔ `app/src/main/assets/` را روی هر هاست استاتیک با HTTPS (GitHub Pages، Netlify و…) آپلود کنید. در گوشی از منوی مرورگر «افزودن به صفحهٔ اصلی» یا از «تنظیمات ← نصب برنامه» استفاده کنید.

## لوگو
- `logo-full.png`: لوگو با اسم
- `app/src/main/assets/logo.svg`: نماد بدون اسم (برداری)
- `icon-192.png` و `icon-512.png`: آیکن وب. آیکن اندروید در `res/mipmap-*` است.

## نکته‌ها
- اگر برنامه را پاک کنید، داده‌ها هم پاک می‌شوند. قبلش از «تنظیمات ← پشتیبان‌گیری» نسخهٔ پشتیبان بگیرید.
- فونت وزیرمتن از اینترنت لود می‌شود. برای فونت همیشگی و آفلاین، از «پشتیبان‌گیری و فونت» فایل B Vazir را بارگذاری کنید.
- تاریخ بیشترین روز دیده‌شده ذخیره می‌شود، پس عقب بردن ساعت گوشی قفل را برنمی‌دارد.
